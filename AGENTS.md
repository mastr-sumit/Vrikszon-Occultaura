# Numerology Website Development Rules

## Tech Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis
- React Hook Form
- Zod

## Project Goal
Build a premium numerology website inspired by the provided reference website.

The structure should remain similar to the reference while significantly improving UI quality, UX, responsiveness, animations, accessibility, and performance.

## Coding Rules

- Always use TypeScript.
- Never use `any`.
- Create reusable components.
- Prefer composition over duplication.
- Never hardcode repeated values.
- Keep components modular.
- Write production-ready code only.

## Styling Rules

- Use Tailwind CSS.
- Follow the design system.
- Use consistent spacing.
- Mobile-first approach.
- Desktop, tablet and mobile must all work.

## Animation Rules

- Use Framer Motion.
- Use Lenis for smooth scrolling.
- Keep animations subtle and premium.
- Avoid excessive motion.

## Accessibility

- Semantic HTML.
- Proper button labels.
- Keyboard accessible.
- Images must have alt text.

## Performance

- Optimize images.
- Lazy load where appropriate.
- Avoid unnecessary re-renders.

## Working Rules

- Never rewrite unrelated files.
- Only work on the requested component.
- Stop after completing the requested task.
- Explain breaking changes before making them.
