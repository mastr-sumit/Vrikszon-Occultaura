# Motion Philosophy

Motion should never exist for decoration.

Every animation must serve one of these purposes:

• Guide attention

• Improve usability

• Reinforce hierarchy

• Increase delight

• Improve storytelling

• Improve conversion

If an animation has no purpose,

do not use it.
