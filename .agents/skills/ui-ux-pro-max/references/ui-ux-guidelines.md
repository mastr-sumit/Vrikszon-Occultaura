# UI/UX Guidelines
## Premium Numerology & Astrology Website

Version: 1.0

Last Updated: July 2026

---

# Mission

Create a website that builds trust within 5 seconds, guides users naturally, and maximizes consultation bookings through elegant design and exceptional user experience.

---

# Core Design Philosophy

The website should feel like:

• Luxury

• Atmospheric

• Spiritual

• Premium

• Elegant

• Ornate & Mystical

• Intelligent

• Modern

The design experience is closer to a premium astrology/spiritual brand experience with rich visual depth — featuring full-bleed atmospheric imagery, dense and confident layouts (not overly spaced out), bold large typography, decorative flourishes (sparkles, ornamental dividers, hexagon motifs), and a premium-but-maximalist feel rather than minimal.

Never feel:

❌ Cheap

❌ Cluttered without intent

❌ Overwhelming

❌ Outdated

❌ Template-based

---

# First Impression Rule

Within the first 5 seconds the visitor should understand:

Who we are

What we do

Why they should trust us

How to book a consultation

---

# Visual Hierarchy

Every page must have:

Primary Focus

↓

Secondary Information

↓

Supporting Information

↓

Call To Action

Never compete for attention.

---

# Layout Density & Atmosphere

Atmospheric depth creates luxury.

Use dense, confident layouts with purposeful content structure.

Full-bleed cosmic background visuals and rich text layout.

High impact typography.

---

# Reading Experience

Maximum text width:

760px

Avoid long paragraphs.

Prefer

2–4 lines.

Use headings frequently.

# Hero Rules

The hero must answer:

Who are we?

What problem do we solve?

Why should users trust us?

What should they do next?

Must include:

Headline

Subheading

Primary CTA

Secondary CTA

Trust Indicators

Background Visual

Scroll Cue

---

# Navigation Rules

Maximum 7 navigation items.

Sticky navigation.

Always visible CTA.

Current page highlighted.

Transparent over hero.

Solid after scroll.

---

# Call To Action Rules

Primary CTA:

Book Consultation

Secondary CTA:

WhatsApp

CTA must appear:

Hero

Services

Testimonials

Footer

Never hide important actions.

---

# Card Design

Cards should be:

Simple

Rounded

Spacious

Soft shadows

Clear icons

Readable

Hover states

Avoid information overload.

---

# Forms

Minimum fields.

Clear labels.

Inline validation.

Large inputs.

Large submit button.

Success confirmation.

Never ask unnecessary information.

---

# Typography Rules

Use typography to create hierarchy.

Never rely only on color.

Headings should communicate meaning before decoration.

Maintain excellent readability.

---

# Images

Only high-quality images.

Professional photography.

Natural expressions.

Authentic moments.

Avoid generic stock photos.

---

# Icons

Single icon style.

Consistent stroke width.

Purposeful.

Never decorative only.

---

# Color Usage

Primary Color

60%

Neutral Colors

30%

Accent Color

10%

Accent should highlight important actions only.

# Conversion Principles

Reduce friction.

Remove unnecessary clicks.

Clear CTA.

Build trust before asking for action.

Explain benefits before features.

---

# Mobile UX

Design mobile first.

Thumb-friendly buttons.

Readable typography.

Simple navigation.

Fast loading.

Avoid horizontal scrolling.

---

# Accessibility

Keyboard navigation.

Visible focus states.

Alt text.

Proper heading hierarchy.

Sufficient color contrast.

Readable font sizes.

Large tap targets.

---

# Performance UX

Perceived speed matters.

Use skeleton loaders.

Lazy loading.

Progress indicators.

Smooth transitions.

No layout shifts.

---

# Empty States

Every empty screen should:

Explain the situation.

Offer guidance.

Provide next action.

---

# Error Handling

Human-friendly messages.

Never blame the user.

Explain how to fix the issue.

---

# Loading Experience

Show progress.

Avoid blank screens.

Keep animations subtle.

---

Hover

Active states

# User Psychology

People buy trust before services.

Design should reduce anxiety.

Guide instead of forcing.

Always answer:

Why us?

Why now?

What happens next?

---

# Don'ts

Don't overload pages.

Don't use more than two fonts.

Don't animate everything.

Don't use bright saturated colors.

Don't create unnecessary complexity.

Don't hide important information.

---

# Golden Rule

Every design decision should improve at least one of these:

Trust

Readability

Accessibility

Conversion

Performance

User Experience

If it improves none of them,

don't implement it.
